The crude prevalence ratios in Chapter 5 mix the association of income with the associations of everything that travels with income. Age is the clearest example: adults 65 and older are less likely than middle-aged adults to have a high household income (many are retired) and far more likely to have diabetes. A multivariable model estimates the association of income with diabetes among adults of the same age group, sex, and race and ethnicity.

6.1 Helpers

The three helper functions are the same as in Chapter 5.

Code 
# Fit one model per completed dataset; keep the estimates, their covariance matrix, and the
# residual degrees of freedom. Each design is built, used, and discarded in turn.
fit_each <- function(imputed, formula) {
  purrr::map(seq_len(imputed$m), \(i) {
    design <- mice::complete(imputed, i) |>
      dplyr::mutate(diabetes_yes = as.integer(diabetes == "Yes")) |>
      srvyr::as_survey_design(
        ids = psu_id,
        strata = strata,
        weights = weight,
        check_strata = FALSE
      )
    fit <- survey::svyglm(
      formula,
      design = design,
      family = stats::quasipoisson()
    )
    list(
      coef = stats::coef(fit),
      vcov = stats::vcov(fit),
      df = stats::df.residual(fit)
    )
  })
}

pool_fits <- function(fits) {
  estimates <- purrr::map(fits, \(fit) {
    tibble::tibble(
      term = names(fit$coef),
      estimate = fit$coef,
      std.error = sqrt(diag(fit$vcov)),
      df.residual = fit$df
    )
  })
  mice::pool.table(purrr::list_rbind(estimates), exponentiate = TRUE)
}

format_pr <- function(pooled) {
  pooled |>
    tibble::as_tibble() |>
    dplyr::filter(term != "(Intercept)") |>
    dplyr::transmute(
      term,
      `PR (95% CI)` = sprintf(
        "%.2f (%.2f to %.2f)",
        estimate,
        conf.low,
        conf.high
      ),
      p = format.pval(p.value, digits = 2, eps = 0.001)
    )
}

6.3 Does income matter overall?

Income has four groups, so it has three PRs, each with its own p-value. To ask whether income is associated with diabetes at all, we test the three coefficients together (null hypothesis: all three are zero on the log scale). mitml::testConstraints() runs this multivariate Wald test across imputations (the “D1” statistic, pooled with Rubin’s rules) from each dataset’s estimates and covariance matrix.

Code 
income_terms <- grep("^income", names(adjusted_fits[[1]]$coef), value = TRUE)
income_test <- mitml::testConstraints(
  qhat = do.call(cbind, purrr::map(adjusted_fits, "coef")),
  uhat = simplify2array(purrr::map(adjusted_fits, \(fit) fit$vcov)),
  constraints = paste0("`", income_terms, "`"), # backticks: the names contain spaces
  method = "D1"
)

6.4 Sensitivity analysis: complete cases

How much did imputation change the results? The same model fit to complete cases drops everyone with a missing value. survey::svyglm() keeps the full design for the variance and gives the dropped respondents no weight in the estimates.

Code 
complete_case <- survey::svyglm(
  diabetes_yes ~ income + age_group + sex + race_eth,
  design = srvyr::as_survey_design(
    brfss_clean,
    ids = psu_id,
    strata = strata,
    weights = weight,
    check_strata = FALSE
  ),
  family = stats::quasipoisson()
)
complete_case_pr <- broom::tidy(
  complete_case,
  conf.int = TRUE,
  exponentiate = TRUE
)
complete_case_n <- stats::nobs(complete_case)

Where do the missing data matter? The fraction of missing information (fmi) is the share of each estimate’s variance that comes from the missing data. It is highest for the income terms, where most values were imputed, and close to zero for variables with nothing missing.

ImportantWhen the two analyses disagree

If complete-case and imputed results differ substantially, report both and explain why, rather than choosing the one you like better. Under MAR the imputed results are the less biased ones; if missingness might depend on income itself (MNAR), neither is guaranteed to be right, and a sensitivity analysis for MNAR is the next step.

6.5 Reporting the results

Code 
top_income <- dplyr::filter(adjusted, term == "income$100,000 or more")
top_income_cc <- dplyr::filter(
  complete_case_pr,
  term == "income$100,000 or more"
)

A results paragraph might read:

We analyzed 457,670 adults in the 2024 Behavioral Risk Factor Surveillance System, representing 263.8 million US adults. All estimates accounted for the survey weights, strata, and primary sampling units. Household income was missing for 19.1% of respondents, and missingness varied with age and general health. We multiply imputed missing values (5 imputations by chained equations with the mice package, version 3.19.0, predictive mean matching, with the survey weight as a predictor) and pooled estimates with Rubin’s rules. In a survey-weighted modified Poisson model adjusted for age group, sex, and race and ethnicity, adults with a household income of $100,000 or more had a prevalence of diabetes 0.47 times that of adults earning less than $25,000 (95% CI 0.44 to 0.50; joint test of income p <0.001). In a complete-case analysis the prevalence ratio was 0.47 (95% CI 0.44 to 0.50).
