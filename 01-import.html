1.1 The Behavioral Risk Factor Surveillance System

The Behavioral Risk Factor Surveillance System (BRFSS) is the largest continuously running health survey in the world. Every year, the Centers for Disease Control and Prevention (CDC) and the states interview hundreds of thousands of US adults by landline and cell phone about their health conditions, health behaviors, and use of health care. In 2024, 457,670 adults in 49 states, the District of Columbia, Guam, Puerto Rico, and the US Virgin Islands completed the interview (Tennessee did not collect enough data to be included).

BRFSS is a complex survey:

  • Strata. Each state’s sample is drawn separately within strata (for example, by region and by landline or cell phone).
  • Primary sampling units (PSUs). Within a stratum, phone numbers are sampled. In BRFSS each respondent is their own PSU.
  • Weights. People are sampled with different probabilities and respond at different rates. CDC’s final weight (_LLCPWT) corrects for both and makes the weighted sample match each state’s adult population by age, sex, race and ethnicity, education, and other characteristics (“raking”).

Every estimate in this book uses all three. Chapter 3 shows what happens when they are ignored.

1.2 Download the data (run once)

CDC distributes the data as a zipped SAS transport file (.XPT), a format that stores a SAS dataset in a portable way. The zip file is 83 MB, and the unzipped file is 1.1 GB.

Run the chunk below once, by hand (it is not run when the book is rendered). It saves data/raw/LLCP2024.XPT. Raw data, processed data and caches are excluded from Git.

Code 
dir.create("../data/raw", showWarnings = FALSE, recursive = TRUE)
zip_file <- "../data/raw/LLCP2024XPT.zip"
options(timeout = 600) # allow 10 minutes on a slow connection
utils::download.file(
  "https://www.cdc.gov/brfss/annual_data/2024/files/LLCP2024XPT.zip",
  destfile = zip_file,
  mode = "wb"
)
# The zip file names its contents "LLCP2024.XPT " (with a trailing space), so rename the file.
extracted <- utils::unzip(zip_file, exdir = "../data/raw")
file.rename(extracted, "../data/raw/LLCP2024.XPT")
file.remove(zip_file)
TipDownloading by hand

You can also download the zip file from the CDC BRFSS 2024 page (“2024 BRFSS Data (SAS Transport Format)”), unzip it, and save the file as data/raw/LLCP2024.XPT. The same page has the codebook, which lists every variable, its question, and its codes.

1.3 Read only the columns we need

The file has 345 columns. We need 14, so we read only those with col_select. This keeps memory use low and makes reading fast. It does not change the survey design: every one of the 457,670 respondents is kept, with their weight, stratum, and PSU.

Names that start with an underscore are variables CDC calculated. In R they must be wrapped in backticks, as in `_LLCPWT`.

Code 
brfss <- haven::read_xpt(
  raw_file,
  col_select = c(
    `_LLCPWT`,
    `_STSTR`,
    `_PSU`,
    `_STATE`, # survey design
    DIABETE4,
    GENHLTH,
    MEDCOST1, # outcomes
    INCOME3, # exposure
    `_AGE_G`,
    SEXVAR,
    `_IMPRACE`, # covariates
    `_AGE80`, # continuous-variable descriptive example
    EDUCA,
    EMPLOY1 # auxiliary variables for imputation
  )
)

# Check: all 457,670 respondents and the 14 columns we asked for.
