Appendix A — Coding Decisions

Every analysis rests on coding decisions. This appendix lists them, with the number of respondents each one affects, so that a reader can check them and a later analysis can change them on purpose rather than by accident.

A.1 Decisions

Decision Reason Respondents affected
“Don’t know”, “refused”, and blank answers become missing and are imputed They carry no information about the true value; dropping them would lose about one adult in five from any model with income Income: 87,423; employment: 8,402; education: 2,363; general health: 1,310; cost barrier: 1,673; diabetes: 1,034
Diabetes told only during pregnancy (DIABETE4 = 2) is “No” Gestational diabetes alone is not current diabetes; the answer settles the value 3,395
Prediabetes counts as “no diabetes” in the 0/1 outcome The outcome is diagnosed diabetes 11,307
Age from _AGE_G (six groups, CDC-imputed) rather than _AGE65YR (two groups) Better adjustment for age, a strong confounder; no missing values All
Numeric age from _AGE80, retained as years with 80 meaning 80 or older Demonstrates a survey-weighted comparison of means; models and imputation retain age groups All
Race and ethnicity from _IMPRACE (CDC-imputed) CDC fills missing answers for weighting; no missing values All
Income in four groups: under $25,000; $25,000-$49,999; $50,000-$99,999; $100,000 or more Enough respondents per group; matches the descriptive tutorials All with an income answer
Reference groups: lowest income, ages 18-24, female, non-Hispanic White Lowest income: PRs describe the gradient from the bottom; non-Hispanic White: largest group All
Prevalence ratios (modified Poisson) rather than odds ratios Diabetes is common, so odds ratios would overstate the ratios of prevalences All models
5 imputations Keeps the classroom example short; assess stability and use more when needed for a substantive analysis All models
Imputation by predictive mean matching for every variable, 5 iterations; the weight as a predictor, state omitted A compact teaching example; assess variable-specific methods, convergence and the effect of including state when adapting it (Chapter 4) All imputed values
