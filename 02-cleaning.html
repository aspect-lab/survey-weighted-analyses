2  Cleaning and Recoding

Code 
source("_common.R")
brfss <- readRDS(file.path(processed_dir, "01-brfss.rds"))

Raw BRFSS answers are numeric codes. Cleaning turns them into labeled categories that R and readers understand. It is also where most analysis errors start: a code that slips through unrecoded (a 99 for “refused” read as an income group) or a missing value silently turned into “no” changes every result that follows.

This chapter follows four rules:

  1. Declare first. Before using an item, write down every value the codebook allows.
  2. Check. Stop if the data hold any other value.
  3. Recode explicitly. Map every value, including missing ones, by hand; never rely on a default to absorb something unexpected.
  4. Count. Report how many answers each coding rule changes (Appendix A).

2.1 Step 1: Declare what each item can be

The values below come from the BRFSS 2024 codebook. BRFSS uses the same codes for non-answers throughout: 7 (or 77) for “Don’t know/Not sure”, 9 (or 99) for “Refused”, and a blank (NA in R) for “Not asked or missing”.

Code 
# Possible values of each item in the BRFSS 2024 codebook. Blank (NA) means "not asked or
# missing".
item_values <- list(
  DIABETE4 = c(1:4, 7, 9), # 1 Yes; 2 Yes, but only during pregnancy; 3 No;
  # 4 No, prediabetes or borderline; 7 Don't know; 9 Refused
  GENHLTH = c(1:5, 7, 9), # 1 Excellent; 2 Very good; 3 Good; 4 Fair; 5 Poor;
  # 7 Don't know; 9 Refused
  MEDCOST1 = c(1, 2, 7, 9), # 1 Yes; 2 No; 7 Don't know; 9 Refused
  INCOME3 = c(1:11, 77, 99), # 1 Less than $10,000 ... 11 $200,000 or more;
  # 77 Don't know; 99 Refused
  `_AGE_G` = 1:6, # 1 18-24; 2 25-34; 3 35-44; 4 45-54; 5 55-64; 6 65+
  `_AGE80` = 18:80, # CDC-imputed age in years; 80 means 80 or older
  SEXVAR = 1:2, # 1 Male; 2 Female
  `_IMPRACE` = 1:6, # 1 White; 2 Black; 3 Asian; 4 American Indian or Alaska
  # Native (all non-Hispanic); 5 Hispanic; 6 Other, non-Hispanic
  EDUCA = c(1:6, 9), # 1 Never attended ... 6 College 4 years or more; 9 Refused
  EMPLOY1 = 1:9, # 1 Employed for wages ... 8 Unable to work; 9 Refused
  `_STATE` = c(1, 2, 4:6, 8:13, 15:42, 44:46, 48:51, 53:56, 66, 72, 78) # FIPS codes
)
# The design variables and the CDC-imputed items are never blank.
never_blank <- c(
  "_LLCPWT",
  "_STSTR",
  "_PSU",
  "_STATE",
  "_AGE_G",
  "_AGE80",
  "SEXVAR",
  "_IMPRACE"
)

The 53 state codes are the 2024 codebook’s: the 50 states except Tennessee (47), plus the District of Columbia (11), Guam (66), Puerto Rico (72), and the US Virgin Islands (78).

2.2 Step 2: Check the data against the codebook

A codebook can be wrong, and a file can change between releases. This check compares every observed value with the declaration and stops, naming each item and value, if anything else appears. It is silent when the data are as declared.

Code 
# Check: every value is in the codebook.
unexpected <- purrr::imap(item_values, \(values, item) {
  setdiff(brfss[[item]], c(values, NA))
}) |>
  purrr::compact()
if (length(unexpected) > 0) {
  stop(
    "Values not in the codebook: ",
    paste0(
      names(unexpected),
      " (",
      purrr::map_chr(unexpected, toString),
      ")",
      collapse = "; "
    )
  )
}
# Check: no blanks where the codebook has none, and every weight is positive.
stopifnot(!anyNA(brfss[never_blank]), all(brfss[["_LLCPWT"]] > 0))

2.3 Step 3: Recode

dplyr::recode_values() maps each code (left of ~) to a value (right of ~). With unmatched = "error", any code we did not list stops the run, so nothing can slip through. tidylog::mutate() works like dplyr::mutate() but reports what each new variable looks like, including its share of missing values.

Four decisions are built into this recoding (Appendix A lists them with counts):

  • Non-answers become missing. “Don’t know”, “refused”, and blank tell us nothing about a person’s true value, so they become NA. Chapter 4 fills them in by multiple imputation rather than dropping those people.
  • Values that other answers settle are coded, not left missing. A woman told she had diabetes only during pregnancy (DIABETE4 = 2) does not have diabetes now, so she is coded “No”.
  • Age and race and ethnicity come from CDC’s imputed versions. CDC fills the few missing answers for these weighting variables (_AGE_G, _IMPRACE), so they are never blank. Six age groups adjust for age much better than two.
  • Reference groups come first. The first level of each factor is the comparison group in the models: the lowest income group, ages 18-24, female, and non-Hispanic White (the largest group).
Code 
brfss_clean <- brfss |>

WarningA common trap with missing values

genhlth %in% c("Fair", "Poor") returns FALSE (not NA) when genhlth is missing, so everyone with a missing answer would be counted as being in good health. Comparisons with == keep missing values missing.

NoteWhy a new PSU identifier?

In BRFSS, PSU codes are only unique within a stratum: PSU 1 in one stratum is a different phone number from PSU 1 in another. survey::svydesign() can combine them itself (nest = TRUE). Numbering each stratum-PSU pair once gives globally unique integer IDs and avoids repeated relabeling and a large nesting cross-tabulation. The speed difference depends on the installed survey backend; the weights, strata and clusters are unchanged. There are 457,670 pairs for 457,670 respondents: in BRFSS each respondent is their own PSU.

2.4 Step 4: Check the recoding

The unmatched = "error" arguments already guarantee that every code was mapped. Four more checks confirm the rules we rely on later, including that every PSU identifier sits in a single stratum, which lets the survey designs in later chapters skip their own (slow) check of the same thing.

Code 
# Check: the "only during pregnancy" answers are now "No", and the 0/1 outcomes are
# missing exactly where the outcomes are.
stopifnot(
  all(brfss_clean$diabetes[brfss_clean$DIABETE4 %in% 2] == "No"),
  identical(is.na(brfss_clean$diabetes_yes), is.na(brfss_clean$diabetes)),
  identical(is.na(brfss_clean$fair_poor), is.na(brfss_clean$genhlth))
)
# Check: each PSU identifier belongs to exactly one stratum (PSUs are nested in strata).
stopifnot(
  nrow(dplyr::distinct(brfss_clean, psu_id, `_STSTR`)) ==
    dplyr::n_distinct(brfss_clean$psu_id)
)
